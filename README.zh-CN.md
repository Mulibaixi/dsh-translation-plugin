# DeepSeek 翻译插件

[English](README.md) | [简体中文](README.zh-CN.md)

用于 DeepSeek Harness（DSH）的轻量翻译会话面板。快译模式使用 DSH 中已有的模型处理纯文本，保留每份已受理材料的处理单元、全部修订和一份最终选择。历史保存默认关闭；开启后保存这些记录、会话资料与当前原文草稿。

同一主题共享术语、实体、事实和关系，通过独立记忆资产视图及限定范围的主模型工具管理。

## 当前功能

- 右侧栏翻译面板，通过标题下拉栏切换已有会话；可折叠的会话侧栏默认收起，每个会话分别保留输入和配置。
- “+”建立新主题及首会话，默认名称为“新翻译会话”；从当前会话新建时，在同主题下统一编号，例如“故事A-01”“故事A-02”。从子会话继续新建也取主题下一个序号，不叠加名称后缀、不回填已删除编号。
- 重命名修改主题名称，同主题会话一起更新显示名，ID 和序号保持不变；每个会话还可设置独立备注，备注允许重复或清空。列表、侧栏和当前标题优先显示备注，悬停仍显示原会话名与备注。
- 面板顶部当前标题左对齐，翻译模式和目标语言右对齐；标题支持下拉与右键操作，下方提供会话内容滚动区、圆形发送按钮和简洁输入框，输入时不显示蓝色聚焦边框。
- 新建或切换会话后，顶部保持一个模式控件与一个目标语言控件，不再累积不可交互的副本。
- 服务检查中、不可用或普通模式未接入的提示紧贴输入框外上方；快译服务状态行右侧提供紧凑检查图标，检查期间禁用，服务就绪后隐藏。已有翻译记录时，记录区统一显示一处历史保留说明。
- 模型选择位于输入框右下角、发送按钮左侧，采用 DSH 原生菜单与图标，并使用主窗口同一 `session.modelCatalog()` 目录接口。菜单包含模型与推理等级，可按提供商分组和搜索；选择只作用于当前翻译会话。
- 输入区工具栏提供文件选择入口，快译禁用。普通模式可选择一个文件、替换或移除，输入区显示文件名；选择按翻译会话隔离，仅在本次打开的面板中保留，重启不恢复。文件读取、解析、上传和翻译尚未接入。
- 快译模式将当前纯文本、目标语言和明确填写的翻译要求发送给所选 DSH Host 模型，并在会话内容区显示原文与译文。仅可选择宿主模型目录提供的模型和推理等级。
- 每个已受理文本单元保留全部译文版本；重译使用该单元原文、语言和要求，采用当前模型选择，不改动输入框中的新草稿。旧版本可以展开，完整版本可以设为唯一最终版。
- 人工编辑会基于原版本保存新修订，不调用模型；会话右键菜单可导出最终译文 TXT 或原文与最终译文成对的对照 JSON。
- **记忆资产**打开独立 Tab，首次以 DSH 应用内浮窗展示。提供译文记录及术语、实体、事实、关系四类结构化档案，支持手动新增/编辑、查看来源、搜索、状态筛选、采用、停用及删除。主模型工具复用同一浏览器权威存储，快译执行不使用这些资产。
- 主模型会话工具可后台新建、重命名主题、修改独立备注及归档/恢复指定会话。标题下拉最上方为**记忆资产**，下方选择或新建会话。资产窗口内可搜索和选择主题，包含没有会话的保留主题；JSON 和 Markdown 一并导出该主题现有的完整术语及结构化档案。
- **DSH 设置 → 翻译**：新会话默认值、历史保存开关及历史清理。有效修改即时保存。

快译执行仅支持纯文本和快译模式；普通模式执行尚不可用。使用前必须在 DSH 中配置 provider 和模型；插件不提供 provider 或凭据设置。每次翻译只使用内置提示词、单元原文、目标语言、明确填写的翻译要求和所选目录模型；不注入工具、主聊天消息或历史、旧译文、文件或记忆。本次运行中执行结果未知时保留原操作身份并查询该操作；Host 确认取消后按已取消结束，不会自动重新提交。

面板保留简约输入区和会话内容区。主模型结构化档案管理已接入，原主发送自动联动和普通翻译执行仍未接通，需要 DSH 正式发送前扩展。主聊天备份、完整知识系统、文件翻译及已受理单元的原文或要求修改尚未接通；保存过的旧人工稿仍可查看。

**重新检查翻译服务**只查询 DSH 宿主翻译服务及运行组件是否就绪，不发送原文或模型翻译请求，也不测试模型凭据和远端响应。Client 会等待 DSH 的异步服务挂载完成后再查询能力，避免服务尚未挂载时误报不可用。

## 重译与最终版本

1. 选择已配置的模型与推理等级，输入原文并发送。Host 受理后建立一个处理单元，其原文、目标语言与要求在后续重译中保持不变。
2. 在该单元点击 **重译**，使用当前模型与推理等级生成新版本。版本记录本次模型选择与时间；输入框里新写的文字仍是另一份草稿。
3. 点击 **展开旧版本** 查看旧译文及状态，**收起旧版本** 可以再次折叠；**详情** 显示模型、推理等级和时间，并在有调用记录时显示提示词版本和 token 使用量。旧版缺少调用证据时只显示选用模型，缺失计数显示“未提供”，实际零计数仍显示零。浏览或复制某版不改变最终选择。
4. 在完整版本上点击 **设为最终**，固定该选择。之后试译保留它，明确选择其他完整版本才会替换。

下一单元真正受理时，直接前一个单元的最新完整版本自动成为最终版，也包括保存后的人工版。开始输入草稿、切会话、归档或关闭面板都不触发定稿。最新尝试失败、不完整或结果未知时，不会悄悄选用更早的成功版；已有最终选择继续保留。历史单元的重译只增加候选版本，需明确选择才替换最终版。导出 TXT 或对照 JSON 时按相同自动规则只收尾范围内各会话的最后一个单元，保留用户固定选择；定稿不调用模型。

## 人工修订与导出

1. 在有非空正文的已结束版本上点击 **编辑**，包括完成、失败、取消或中断版本。修改译文后选择 **保存为新版本** 或 **取消**；已结束的半截结果可以人工修正为完整版本。新版本记录界面显示的来源版本，不修改该单元的原文、语言或要求；后来到达的模型结果不会悄悄替换编辑基准。
2. 人工保存先建立候选；**设为最终**才明确固定。候选也可在下一单元受理或 TXT/对照 JSON 收尾最后单元时按完整资格自动选中。人工版本没有模型调用、route 或用量。未保存的编辑草稿仅在本次运行中保留，切会话可继续编辑，重载后丢失。
3. 右键会话标题或名称，选择 **导出译文 TXT**，再选 **当前会话**（被点击的会话）或 **整个主题**（同主题全部会话，包含归档）。操作只收尾范围内各会话的最后单元，按固定会话序号和文本编号拼接最终正文。缺少最终版时列出会话和文本编号，可选择 **仅导出已定稿** 生成冻结的部分文件，或取消；不会用失败、半截结果代替最终版，没有任何最终译文时不能生成文件。被点击会话为空时，同主题其他会话有记录仍可导出整个主题。
4. 选择 **导出对照 JSON**，再选相同的范围，按会话分组保存原文与最终译文对，包含会话名称、备注、固定序号和导出时间。操作采用与 TXT 相同的末单元收尾及缺项确认；部分文件保留缺项标记和 `translation: null`。文件不包含草稿、修订历史或调用 metadata。当前不提供 JSON 导入或恢复功能。

编辑、最终选择与导出不调用模型。快译升为普通后，已有文本记录仍可编辑和导出，普通执行仍未接通。关闭历史保存时也可明确导出当前快照；导出不会打开历史保存开关或另建自动历史副本，收尾的最终选择是否持久化遵循已有开关。导出文件另由用户通过浏览器保存；界面只提示已向浏览器发起下载，不宣称文件已经保存。

## 主题档案与主模型管理

点击标题下拉最上方的**记忆资产**，或使用会话右键菜单的**记忆**操作，打开独立资产 Tab。点击资产标题栏的小灰字主题名，搜索和选择所属主会话下的主题，包含没有会话的保留主题；选择仅改变资产视图。同一稳定主题下的会话共享术语、实体、事实和关系，重命名不改变身份，新主题初始为空。状态包括待确认、生效、待复核及已停用；术语另有冲突状态。

资产视图固定所属主会话，再次打开记忆资产复用窗口并选择请求的主题。新开视图在所属主会话可见时于 DSH 应用内浮出，已有或恢复的 Tab 保持原停靠/浮动状态。标题栏一行显示固定粗体**记忆资产**、常规字重的会话备注或名称，以及灰色可交互主题名；标题使用宿主标题栏剩余宽度，名称自然排布，仅在整体超出可用空间时省略。宿主停靠/关闭控件仍在同一行。没有会话的保留主题显示**无关联会话**。正文移除重复的会话/主题标题。标题文字和空白保留拖动，主题按钮打开选择菜单；关闭、停靠、移动及缩放仍由宿主处理，正文不另设关闭按钮，也不提供 Windows 原生子窗口。切换主题、分类或条目保留未保存编辑稿，关闭视图释放草稿并保留资产；切离翻译 Tab 时保留当前人工编辑稿。

进入**结构化档案**后，通过**档案类型**选择术语、实体、事实或关系。**译文记录**显示该主题已有文本单元的只读原文、当前最终译文，并仅在最新版本完整时显示候选，不跳过新失败版本寻找旧成功。点击**编辑译文**后**保存新版本**，建立不调用模型的不可变人工候选；**设为最终**独立执行。原文和机器执行记录不被改写，归档记录仍可阅读，编辑前须恢复会话。**其他记忆**与**临时文件**暂未开放。主题、分类、类型和条目切换保留挂载视图内的未保存编辑稿，关闭视图时释放。

在结构化档案点击**新增术语**或**编辑术语**，修改原文形式/别名、语言、义项和首选/避免译法后，点击**保存并采用**。一次保存即可新增或更新为用户明确确认的生效规则，不再要求第二次采用确认。原位编辑保留条目 ID、创建时间和作为示例的来源引用。版本陈旧或规则冲突会提示，不覆盖其他条目，未保存表单内容保留供核对。模型工具不能使用这项用户编辑权限或覆盖已确认用户规则。

点击**新增实体**填写名称、别名和描述；**新增事实**填写标题、事实内容及关联实体；**新增关系**选择源实体及目标实体，填写关系和描述。保存并采用建立用户明确确认的条目，实体关联限定在本主题。被引用实体变化、停用或删除后，相关事实及关系待复核，不会自动改指其他实体。其他窗口删除正在编辑的实体、事实或关系时，未保存稿保留供复制，保存按钮禁用。

搜索和状态筛选只影响所选类型的列表，不搜索证据正文；导出仍含整个主题的完整快照。术语搜索匹配原文形式、别名、首选/避免译法与义项。宽视图列表与详情分别滚动，窄视图使用单列；筛选保留于挂载视图，不在关闭后持久保存。

十三个工具仅属于当前主会话的 Agent，通过双向桥访问浏览器权威记录：列出主题/会话、新建会话、重命名主题、设置会话备注、归档/恢复会话、读取明确提供的历史单元、列出/检索/提交术语，以及列出/检索/提交实体、事实和关系。新档案列出及提交使用明确主题 ID，包含没有会话的保留主题；检索通过指定翻译会话推导真实主题和档位。工具不直接删除会话或档案条目、修改草稿或模型选择、改变默认设置或自动升级档位。

新建须明确起点：新主题、父会话或已有主题。新主题用于用户明确要求的新主题；同主题子会话可在已交付任务范围内由主模型组织，无需每次额外确认。父会话起点继承配置，草稿及备注为空；已有主题采用存活会话的配置，没有会话时使用当前默认值。后台新建和恢复保持用户当前焦点，新建理由只放工具回执，不自动写成备注。主题重命名影响该主题所有会话，备注和归档只针对指定会话；预期名称、备注和归档状态在既有主题锁内核对。回执区分已保存和仅本次运行，保存失败会说明内存可能已变化，应查询当前记录，不假称已回滚。

推断保持提案；有可读原文依据且无冲突的核对项可以直接生效，提案则由用户明确点击**采用**。模型不能覆盖已采用的用户规则；冲突需明确处理，不以最新建议取胜。**停用**保留条目供查看，**重新采用**经冲突检查后明确恢复生效；**删除**经确认后移除该共享条目。

依据引用已有原文或最终译文，不重复正文；模型提交只能引用用户明确提供的历史单元。来源删除或变化后，派生条目待复核，检索立即排除失效依据；最终依据包含选择事件，重新选回相同旧修订也不会恢复旧依据。来源示例丢失不撤销独立采用的用户规则。术语按同所属主会话、主题、语言和明确源形式/别名精确匹配；实体、事实和关系按名称、别名、标题、关系或关联生效实体名匹配，不任意猜测子串。快译检索为空，快译定稿也不自动提炼档案。

需要讨论已有历史时，已升为普通的会话可在已结束单元上点击**供主模型参考**，并通过**取消参考**撤回。范围只包括该单元冻结后的原文、要求、各版译文及最终元数据，不读取当前草稿或未选择的历史。参考选择仅留本次运行，**更新主模型参考**刷新已选快照。此项是可选历史共享，不是每次翻译必须增加的步骤，也不发送翻译请求或接通普通执行。原主发送自动联动仍等待 DSH 正式扩展；当前不提供手动两步发送流程。

历史开关也控制术语及实体/事实/关系持久化：开启时独立保存主题快照，关闭保留旧副本、后续编辑仅留本次运行，重新开启纳入仍在内存中的内容。读写失败保留输入及当前事实，冲突需明确读取最新副本。保存失败时内存可能已变化而本地副本未更新，应查询当前版本再重试。档案不保存重复原文/最终正文、主聊天备份、Host 能力或凭据；会话 TXT/对照 JSON 不包含这些独立档案。

### 导出主题档案快照

打开**记忆资产**并选择主题，进入**结构化档案**，最后一个会话已删除的主题仍可导出。**导出 JSON**和**导出 Markdown**一并冻结当前完整术语、实体、事实及关系快照，不受所选类型或列表筛选影响。保留所有状态、内容、版本、采用记录、更新/导出时间、实体关联、证据引用及可读性标签，待确认、有冲突、依据不可用和停用项保持相应标注。

文件只包含现有档案，不含来源正文、主聊天或完整主题备份。导出不调用模型、不触发提炼或整理、不改变档案或最终选择，不打开历史开关或另建自动历史副本；关闭保存时也可导出。JSON 没有导入功能。文件由用户通过浏览器保存，下载提示不代表文件已保存。

## 会话与默认设置

进入一个主窗口会话并展开右侧栏，从引导入口打开“翻译”。当前翻译会话按所属主窗口会话分别管理；每个翻译会话有自己的独立 ID。此归档范围不代表快译执行会使用主模型。

- 点击当前标题展开已有会话，选择后切换并保留各会话输入；下拉底部的居中 **+** 创建新主题及首会话，下拉中也提供恢复归档入口。
- 标题下拉最上方仅设一个**记忆资产**入口；窗口内可搜索和选择所属主会话下的主题，没有会话的保留主题也可打开资产。
- 在标题下拉或侧栏中长按会话行约 400 毫秒，再拖动调整顺序。两处列表共用排序，新会话追加到末尾，归档恢复保留排序位置。排序仅按所属主会话独立保存本地会话 ID，不受历史保存开关影响，不改变名称、固定编号或导出顺序。使用中会话末尾的居中 **+** 同样创建新主题及首会话。两个 **+** 入口均可整行点击，侧栏中的范围与会话名称行一致。
- 右键会话名称或顶部当前标题，依次显示 **新建子会话、重命名、备注、记忆、导出译文 TXT、导出对照 JSON、归档/恢复、删除**。重命名确认框说明影响同主题会话。选择导出格式后收起标题下拉，显示范围选项，**返回**回到操作列表；其他操作先收起两层菜单，再打开确认框或执行。Escape 或点击外部关闭右键菜单，重开从操作列表开始。操作绑定被点击的会话，无需先切换。
- 归档保留内容、从使用列表移除。展开 **已归档** 后点击会话可恢复使用，也可右键选择 **恢复**；没有关闭会话功能。
- 会话侧栏默认收起，顶部侧栏图标可展开或收起列表。会话名称过长时省略显示，悬停可查看完整名称。
- 历史保存关闭时，未落盘内容及归档/恢复等变化只在当前窗口保留，刷新、重启或插件重载后丢失。开启后自动保存当前窗口内会话，包括归档状态。

模型菜单先选择 **模型**，再通过 **推理等级** 选择适配器提供的等级；菜单字号与目标语言菜单一致，包括“自定义目标语言”的标签和输入。模型搜索不显示蓝色聚焦外框。模型与等级列表不设返回项，关闭后重新打开菜单即可回到入口。适配器允许未指定等级时提供 **Default**；未提供推理元数据的模型会明确提示，没有可选等级。

进入模型或推理等级列表、搜索结果变化时，原生菜单定位随之更新。

新主题的首会话从设置复制翻译模式、目标语言、翻译要求与单次上限；同主题子会话复制父会话的配置，包括模型与推理等级，但输入为空。已有会话不会因默认值变化而被改写。会话只允许从快译升为普通，保留输入；普通不能降为快译，同主题其他会话也不会被自动升档。

模型与推理等级偏好独立保存，不受历史开关影响。可恢复的翻译会话保留各自选择；新主题首会话沿用所属主窗口会话的最后选择。完全临时会话在重启后不恢复，但所属主窗口的最后模型偏好保留。同主题子会话优先继承父选择，包括明确未选模型的情况；其他已有会话仍保留各自选择。存储失败时保留当前选择并提示。当前 Host 目录已失效的选择仍可查看，但不能用于发送。

| 设置 | 默认值与行为 |
| --- | --- |
| 翻译模式 | 快译。 |
| 目标语言 | 中文。 |
| 翻译要求 | 留空；最多 4000 个 Unicode 字符。 |
| 单次上限 | 原文 20000 个 Unicode 字符，可设为 1–200000；不是 token 上限。 |
| 允许保存会话历史到本地 | 关闭；开启后保存主题名称、会话资料、归档状态、当前原文草稿、已受理文本单元、全部修订和最终选择，供重启恢复，并独立保存主题术语及实体/事实/关系快照；模型与推理等级偏好独立保存。不包含所选文件。 |

**恢复默认设置**位于设置页顶部。恢复默认会关闭后续历史保存，已有会话和历史保留。设置页没有统一的保存按钮；无效输入或存储失败会保留编辑值并显示错误。其他窗口修改的设置自动同步。

## 会话历史与删除

历史与模型偏好使用当前设备当前 Web origin 的 `localStorage`，数据为明文，不跨设备同步，不写入 Host profile patch，不保存 API 密钥或 Host 能力句柄。开启**允许保存会话历史到本地**后，历史保存主题/会话身份、固定序号、名称、备注、归档状态、当前原文草稿和默认值快照，以及已受理单元的原文、要求、语言、全部机器/人工修订、执行状态、安全实际调用 metadata 及最终选择，供重启恢复。每个修订正文只保存一份，事件与最终选择通过引用关联；不包含未保存的编辑草稿。

恢复记录不会继续或重新发送模型请求。重启前正在执行或未结算的修订显示 **重启前未确认／已中断**，原结果未知的情况会在说明中区分；核对后明确重译才会在同一个用户单元中发起新请求，恢复记录不能查询旧 Host 操作。新草稿在受理前失败时尚无已保存单元，其临时执行卡片不会恢复。所选文件也不进入历史，关闭面板、切换所属主窗口会话或删除所属翻译会话后释放；选择文件不代表已上传或可以执行文件翻译。DSH 模型消息历史尚未接入。

关闭历史保存后，已有历史继续保留，后续重命名、新单元、修订和最终选择只留在当前运行中，不替换已保存副本。模型偏好继续独立保存，只包含提供商 ID、模型 ID 与可选推理等级，恢复时为已有会话采用最新选择，不改写旧历史正文。删除会话会清除其专属偏好；历史清理保留所属主窗口的最后模型偏好，用作新会话默认选择。已保存主题仍保留不含正文的身份与编号记录，以避免重启后重用已发放序号；完全临时的新主题不因此落盘。重新开启会保存仍在内存中的当前内容，包括关闭期间的变化，不能恢复此前已经丢失的内容。设置页提供：

- **清除历史快译**：只处理已保存的快译会话。
- **清除所有会话历史**：处理本插件所有已保存会话，确认范围包含无法读取的历史副本。
- **删除所选历史**：勾选单条或多条会话后删除。

删除前需要确认，成功后从会话列表移除；右键删除同时处理该会话的内存内容与已保存历史。删除一个会话不会连带删除它的父子会话，历史清理范围包含已归档记录。主题术语默认保留，删除最后一个会话也不清除档案；需要一并清除时，在确认框明确勾选联动删除所选主题术语，未选中的同主题会话也会失去这些术语。确认同时冻结并检查会话与术语版本，陈旧范围拒绝执行；部分失败报告剩余范围，多项存储移除不宣称原子完成。

实体、事实和关系独立保留，会话删除、历史清理及联动术语勾选均不删除这些条目。请在记忆资产中明确删除；历史关闭时仍可删除已保存条目，不借此保存其他临时编辑。

持久主题的新建、编号、重命名和相关存储操作使用浏览器 Web Locks 协调。环境不支持安全协调时，会提示能力不足并限制相关持久操作；纯临时内容仍可保留在当前窗口。锁只协调本版本参与相同协议的窗口，不把多项 `localStorage` 写入变成数据库事务。

读取或保存失败时保留当前输入；陈旧写入会提示冲突，读取本地副本需确认，覆盖必须显式选择。部分清理失败时会报告未完成状态；删除记录用于阻止旧副本再次自动导入。删除全部会话不重置仍保留主题的编号。

旧 v1 草稿和 schema2/3/4 会话可兼容读取。旧会话按可确认的父子关系归入主题并使用统一编号，旧显示名保留供查看；无法确认的关系保守分开。迁移不代表恢复了旧版从未记录的已删除编号。仅兼容读取不会改写已保存正文，明确开启保存或开启后的编辑才写入当前格式。包含文本记录的快照使用 schema5/history2，空记录仍使用 schema3；0.4.x 及更早版本不能读取 schema5。降级前请备份应用本地数据，避免用旧版修改同一份历史。导出的对照 JSON 是原文/最终译文对照文件，当前不提供导入或恢复，不能代替上述备份。

旧版手动保存开关不会自动启用新版历史自动保存；新开关默认关闭。禁用或卸载插件不自动删除本机历史、档案或偏好，需要清理时请先明确操作。

## 兼容性与安装

插件面向 DSH `0.2.0-rc.2` 组件。自动检查覆盖 Quick Host/Client、挂载、主题工具与存储，使用一次性合成 profile 和 provider。UI 与浏览器下载检查为模拟，Menu/Sidebar 契约检查使用安装组件的实际逻辑及合成尺寸/actions；不覆盖真实远端模型、实际桌面 DOM、文件保存对话框或浮窗移动、缩放与停靠。其他 DSH 版本、操作系统和独立 Web profile 未验证，不支持 Windows 原生子窗口。

需要 Node.js 22 或更高版本、pnpm，以及支持本地 bundle 的 DSH。

```powershell
pnpm install --frozen-lockfile
pnpm build
```

在 DSH 插件管理器中将本目录作为 `dsh-translation-plugin` 本地 bundle 安装，启用后重启。构建产物位于 `dist/`，不进入 Git；目录链接安装修改后重建同一目录。升级至 v0.9.3 须加载同版本 Host/Client，刷新 Client 注册（没有刷新功能时重新安装）后重启。既有会话 schema5/history2 和术语 schema1 不变，实体/事实/关系使用独立 schema1 命名空间，无需迁移旧记录。降级前备份应用数据，旧版不管理新增档案。

从早期框架版升级时，需要在插件管理器刷新包含模型目录 RPC 的 bundle 元信息；没有刷新功能时卸载后重新安装，再重启 DSH。不要手动修改 profile。

若曾以 `dsh-deepseek-translation-plugin` 安装，请卸载旧名称后重新安装。启动异常时使用桌面端恢复选项禁用第三方插件，再查看诊断日志。

## 开发与许可证

请阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 和 [AGENTS.md](AGENTS.md)。提交采用 Conventional Commits，描述及正文使用中文；内部设计资料在本仓库之外管理。

`pnpm test` 会先构建，再验证会话、历史、旧格式兼容、目录及 Client 交互。Native 集成命令及 DSH 组件前提见 [CONTRIBUTING.md](CONTRIBUTING.md)。Synthetic provider 不能验证真实远端模型或实际桌面集成。

共享调用记录模块提供 RPC 可选 metadata，包含实际模型、推理等级、输出上限、提示词版本及已报告 token 使用量；Client 详情显示已记录的模型、推理等级、提示词版本和用量，已保存的浏览器记录另包含输出上限。未取得的配置版本与计数保持 `null`，不凭当前提示词推断旧调用；人工修订没有调用 metadata。

术语与实体/事实/关系核心定义有范围的依据、版本、采用和精确检索。唯一共享的 `TopicMemoryStore` 与 `TopicArchiveStore` 沿用既有 Web Locks 和历史开关，`SessionStore` 仍是原文及最终选择权威。Host 只持有运行期范围，不另存档案或历史数据库；一次合并的远程贡献注册快译与主题管理命名空间。

会话管理在结构锁内核对预期元数据，界面选中其新建或恢复的会话，模型工具后台操作。主题档案 JSON/Markdown 纯函数投影冻结的术语及结构化快照与引用标签，不重复证据正文。

变化见 [CHANGELOG.md](CHANGELOG.md)。当前本地版本为 `v0.9.6`，会话备注在列表、侧栏及当前标题中替代原会话名，悬停内容保持不变。记忆资产标题固定粗体标签，会话与主题名仅在标题整体超出可用空间时省略；译文记录说明移至标题旁。导出提示和档案保存状态也更加紧凑。实体、事实、关系档案、主模型工具及综合主题 JSON/Markdown 导出继续可用；纯文本快译、重译、人工修订、最终选择、单会话/主题 TXT 与对照 JSON、可选恢复及独立模型/排序偏好保持。其他记忆、临时文件、文件翻译和完整知识系统暂未开放；普通执行与原主发送自动联动仍需要 DSH 正式扩展。本地版本未远程发布，`private: true` 防止意外 npm 发布。
