# DeepSeek 翻译插件

[English](README.md) | [简体中文](README.zh-CN.md)

用于 DeepSeek Harness（DSH）的轻量翻译会话面板。快译模式使用 DSH 中已有的模型处理纯文本，保留每份已受理材料的处理单元、全部修订和一份最终选择。历史保存默认关闭；开启后保存这些记录、会话资料与当前原文草稿。

v0.6.0 已加入主题术语和主模型管理。

## 当前功能

- 右侧栏翻译面板，通过标题下拉栏切换已有会话；可折叠的会话侧栏默认收起，每个会话分别保留输入和配置。
- “+”建立新主题及首会话，默认名称为“新翻译会话”；从当前会话新建时，在同主题下统一编号，例如“故事A-01”“故事A-02”。从子会话继续新建也取主题下一个序号，不叠加名称后缀、不回填已删除编号。
- 重命名修改主题名称，同主题会话一起更新显示名，ID 和序号保持不变；每个会话还可设置独立备注，备注允许重复或清空。
- 面板顶部当前标题左对齐，翻译模式和目标语言右对齐；标题支持下拉与右键操作，下方提供会话内容滚动区、圆形发送按钮和简洁输入框，输入时不显示蓝色聚焦边框。
- 新建或切换会话后，顶部保持一个模式控件与一个目标语言控件，不再累积不可交互的副本。
- 服务检查中、不可用或普通模式未接入的提示紧贴输入框外上方；快译服务状态行右侧提供紧凑检查图标，检查期间禁用，服务就绪后隐藏。已有翻译记录时，记录区统一显示一处历史保留说明。
- 模型选择位于输入框右下角、发送按钮左侧，采用 DSH 原生菜单与图标，并使用主窗口同一 `session.modelCatalog()` 目录接口。菜单包含模型与推理等级，可按提供商分组和搜索；选择只作用于当前翻译会话。
- 输入区工具栏提供文件选择入口，快译禁用。普通模式可选择一个文件、替换或移除，输入区显示文件名；选择按翻译会话隔离，仅在本次打开的面板中保留，重启不恢复。文件读取、解析、上传和翻译尚未接入。
- 快译模式将当前纯文本、目标语言和明确填写的翻译要求发送给所选 DSH Host 模型，并在会话内容区显示原文与译文。仅可选择宿主模型目录提供的模型和推理等级。
- 每个已受理文本单元保留全部译文版本；重译使用该单元原文、语言和要求，采用当前模型选择，不改动输入框中的新草稿。旧版本可以展开，完整版本可以设为唯一最终版。
- 人工编辑会基于原版本保存新修订，不调用模型；会话右键菜单可导出最终译文 TXT 或完整浏览器会话记录 JSON。
- **主题术语**打开同主题共享的紧凑列表，可查看来源与状态、采用提案、停用或删除条目。主模型有范围的工具通过浏览器权威存储管理术语；快译执行不使用这些资产。
- 主模型会话工具可后台新建、重命名主题、修改独立备注及归档/恢复指定会话。标题下拉的**主题档案**包含没有会话的保留主题；术语面板可将现有快照导出为 JSON 或可读 Markdown。
- **DSH 设置 → 翻译**：新会话默认值、历史保存开关及历史清理。有效修改即时保存。

快译执行仅支持纯文本和快译模式；普通模式执行尚不可用。使用前必须在 DSH 中配置 provider 和模型；插件不提供 provider 或凭据设置。每次翻译只使用内置提示词、单元原文、目标语言、明确填写的翻译要求和所选目录模型；不注入工具、主聊天消息或历史、旧译文、文件或记忆。本次运行中执行结果未知时保留原操作身份并查询该操作；Host 确认取消后按已取消结束，不会自动重新提交。

面板保留简约输入区和会话内容区。主模型术语管理已接入，原主发送自动联动和普通翻译执行仍未接通，需要 DSH 正式发送前扩展。主聊天备份、完整知识系统、文件翻译及已受理单元的原文或要求修改尚未接通；保存过的旧人工稿仍可查看。

**重新检查翻译服务**只查询 DSH 宿主翻译服务及运行组件是否就绪，不发送原文或模型翻译请求，也不测试模型凭据和远端响应。Client 会等待 DSH 的异步服务挂载完成后再查询能力，避免服务尚未挂载时误报不可用。

## 重译与最终版本

1. 选择已配置的模型与推理等级，输入原文并发送。Host 受理后建立一个处理单元，其原文、目标语言与要求在后续重译中保持不变。
2. 在该单元点击 **重译**，使用当前模型与推理等级生成新版本。版本记录本次模型选择与时间；输入框里新写的文字仍是另一份草稿。
3. 点击 **展开旧版本** 查看旧译文及状态，**收起旧版本** 可以再次折叠；**详情** 显示模型、推理等级和时间，并在有调用记录时显示提示词版本和 token 使用量。旧版缺少调用证据时只显示选用模型，缺失计数显示“未提供”，实际零计数仍显示零。浏览或复制某版不改变最终选择。
4. 在完整版本上点击 **设为最终**，固定该选择。之后试译保留它，明确选择其他完整版本才会替换。

下一单元真正受理时，直接前一个单元的最新完整版本自动成为最终版，也包括保存后的人工版。开始输入草稿、切会话、归档或关闭面板都不触发定稿。最新尝试失败、不完整或结果未知时，不会悄悄选用更早的成功版；已有最终选择继续保留。历史单元的重译只增加候选版本，需明确选择才替换最终版。导出最终 TXT 时按相同自动规则只收尾最后一个单元，保留用户固定选择；定稿不调用模型。

## 人工修订与导出

1. 在有非空正文的已结束版本上点击 **编辑**，包括完成、失败、取消或中断版本。修改译文后选择 **保存为新版本** 或 **取消**；已结束的半截结果可以人工修正为完整版本。新版本记录界面显示的来源版本，不修改该单元的原文、语言或要求；后来到达的模型结果不会悄悄替换编辑基准。
2. 人工保存先建立候选；**设为最终**才明确固定。候选也可在下一单元受理或最终 TXT 收尾最后单元时按完整资格自动选中。人工版本没有模型调用、route 或用量。未保存的编辑草稿仅在本次运行中保留，切会话可继续编辑，重载后丢失。
3. 右键会话标题或名称，选择 **导出最终译文 TXT**。操作只收尾最后单元，再按单元顺序导出最终选择。缺少最终版时列出文本编号，可选择 **仅导出已定稿** 生成部分文件，或取消；不会用失败、半截结果代替最终版，没有任何最终译文时不能生成导出文件。
4. 选择 **导出完整记录 JSON**，保存导出时间、会话资料与草稿、全部已受理单元、修订、事件、最终指针及安全调用字段；此操作不定稿。文件不包含未受理新稿的临时执行卡、Host 句柄、凭据、完整 provider 配置或主聊天历史。只有明确记录的调用才附对应固定提示词定义；旧 `callRecord: null` 保持未知。当前不提供 JSON 导入或恢复功能。

编辑、最终选择与导出不调用模型。快译升为普通后，已有文本记录仍可编辑和导出，普通执行仍未接通。关闭历史保存时也可明确导出当前快照；导出不会打开历史保存开关或另建自动历史副本，收尾的最终选择是否持久化遵循已有开关。导出文件另由用户通过浏览器保存；界面只提示已向浏览器发起下载，不宣称文件已经保存。

## 主题术语与主模型管理

从当前标题下拉或会话右键菜单打开**主题术语**。同一稳定主题下的会话共享一份档案，重命名不改变身份，新主题初始为空。详情显示语言、义项、别名、避免译法、条目版本和来源引用；状态包括待确认、生效、有冲突、待复核及已停用。

十个工具仅属于当前主会话的 Agent，通过双向桥访问浏览器权威记录：列出主题/会话、新建会话、重命名主题、设置会话备注、归档/恢复会话、读取明确提供的历史单元、列出/检索术语及提案或核对条目。列出术语可用会话 ID 或主题 ID，包含没有会话的保留主题。工具不直接删除会话、修改草稿或模型选择、改变默认设置或自动升级档位。

新建须明确起点：新主题、父会话或已有主题。新主题用于用户明确要求的新主题；同主题子会话可在已交付任务范围内由主模型组织，无需每次额外确认。父会话起点继承配置，草稿及备注为空；已有主题采用存活会话的配置，没有会话时使用当前默认值。后台新建和恢复保持用户当前焦点，新建理由只放工具回执，不自动写成备注。主题重命名影响该主题所有会话，备注和归档只针对指定会话；预期名称、备注和归档状态在既有主题锁内核对。回执区分已保存和仅本次运行，保存失败会说明内存可能已变化，应查询当前记录，不假称已回滚。

推断保持提案；有可读原文依据且无冲突的核对项可以直接生效，提案则由用户明确点击**采用**。模型不能覆盖已采用的用户规则；冲突需明确处理，不以最新建议取胜。**停用**保留条目供查看，**重新采用**经冲突检查后明确恢复生效；**删除**经确认后移除该共享条目。

依据引用已有原文或最终译文，不把正文再复制进术语档案。来源删除或变化后，派生条目待复核，检索立即排除失效依据；最终依据还包含选择事件，重新选回相同旧修订也不会恢复旧依据。来源示例丢失不撤销独立采用的用户规则。检索只按同所属主会话、主题、语言和明确给出的源形式/别名精确匹配，不从英文或代码全文任意猜测子串。快译检索为空，快译定稿也不自动提炼术语。

需要讨论已有历史时，已升为普通的会话可在已结束单元上点击**供主模型参考**，并通过**取消参考**撤回。范围只包括该单元冻结后的原文、要求、各版译文及最终元数据，不读取当前草稿或未选择的历史。参考选择仅留本次运行，**更新主模型参考**刷新已选快照。此项是可选历史共享，不是每次翻译必须增加的步骤，也不发送翻译请求或接通普通执行。原主发送自动联动仍等待 DSH 正式扩展；当前不提供手动两步发送流程。

历史开关也控制术语持久化：开启时每个主题独立保存一份，关闭保留旧副本、后续修改仅留本次运行，重新开启纳入仍在内存中的当前内容。读写失败保留当前事实；冲突不覆盖另一窗口，通过**读取最新术语**明确加载最新副本。术语记录不保存重复原文/最终正文、主聊天备份、Host 能力或凭据。现有 TXT/JSON 会话导出不包含独立术语档案。

### 导出主题术语快照

从标题下拉的**主题档案**打开主题，最后一个会话已删除的主题仍可进入。在术语面板点击**导出 JSON**或**导出 Markdown**。两种格式冻结当前浏览器快照，包含所有状态、术语内容、版本、采用记录、更新/导出时间、证据引用及可读性标签；待确认、有冲突、依据不可用和停用项保留标注，不将其呈现为生效规则。

文件只包含现有术语档案，不含来源正文、主聊天或完整主题备份。导出不调用模型、不触发提炼或整理、不改变条目或最终选择，不打开历史开关或另建自动历史副本；关闭保存时也可导出。JSON 没有导入功能。文件由用户通过浏览器保存，下载提示不代表文件已保存。

## 会话与默认设置

进入一个主窗口会话并展开右侧栏，从引导入口打开“翻译”。当前翻译会话按所属主窗口会话分别管理；每个翻译会话有自己的独立 ID。此归档范围不代表快译执行会使用主模型。

- 点击当前标题展开已有会话，选择后切换并保留各会话输入；下拉底部的居中 **+** 创建新主题及首会话，下拉中也提供恢复归档入口。
- 标题下拉的**主题档案**列出当前所属主会话下的保留主题，没有会话的主题也可打开共享术语。
- 会话侧栏按创建顺序显示使用中的会话；末尾的居中 **+** 同样创建新主题及首会话。两个 **+** 入口均可整行点击，侧栏中的范围与会话名称行一致。
- 右键会话名称或顶部当前标题，可新建同主题会话、重命名主题、编辑会话备注、导出 TXT/JSON、删除或归档。重命名确认框说明影响同主题会话。打开右键菜单时标题下拉栏保持显示；选择操作后先收起两层菜单，再打开确认框或执行操作。Escape 先退出右键菜单，点击外部收起两层菜单。操作绑定被点击的会话，无需先切换。
- 归档保留内容、从使用列表移除。展开 **已归档** 后点击会话可恢复使用，也可右键选择 **恢复归档**；没有关闭会话功能。
- 会话侧栏默认收起，顶部侧栏图标可展开或收起列表。会话名称过长时省略显示，悬停可查看完整名称。
- 历史保存关闭时，未落盘内容及归档/恢复等变化只在当前窗口保留，刷新、重启或插件重载后丢失。开启后自动保存当前窗口内会话，包括归档状态。

模型菜单先选择 **模型**，再通过 **推理等级** 选择适配器提供的等级；菜单字号与目标语言菜单一致，包括“自定义目标语言”的标签和输入。模型搜索不显示蓝色聚焦外框。模型与等级列表不设返回项，关闭后重新打开菜单即可回到入口。适配器允许未指定等级时提供 **Default**；未提供推理元数据的模型会明确提示，没有可选等级。

v0.7.1 补丁在进入模型或推理等级列表时更新原生菜单定位；用户反馈的桌面闪烁仍待复测确认。

新主题的首会话从设置复制翻译模式、目标语言、翻译要求与单次上限；同主题子会话复制父会话的配置，包括模型与推理等级，但输入为空。已有会话不会因默认值变化而被改写。会话只允许从快译升为普通，保留输入；普通不能降为快译，同主题其他会话也不会被自动升档。

模型与推理等级偏好独立保存，不受历史开关影响。可恢复的翻译会话保留各自选择；新主题首会话沿用所属主窗口会话的最后选择。完全临时会话在重启后不恢复，但所属主窗口的最后模型偏好保留。同主题子会话优先继承父选择，包括明确未选模型的情况；其他已有会话仍保留各自选择。存储失败时保留当前选择并提示。当前 Host 目录已失效的选择仍可查看，但不能用于发送。

| 设置 | 默认值与行为 |
| --- | --- |
| 翻译模式 | 快译。 |
| 目标语言 | 中文。 |
| 翻译要求 | 留空；最多 4000 个 Unicode 字符。 |
| 单次上限 | 原文 20000 个 Unicode 字符，可设为 1–200000；不是 token 上限。 |
| 允许保存会话历史到本地 | 关闭；开启后保存主题名称、会话资料、归档状态、当前原文草稿、已受理文本单元、全部修订和最终选择，供重启恢复，并独立保存共享主题术语；模型与推理等级偏好独立保存。不包含所选文件。 |

**恢复默认设置**位于设置页顶部。恢复默认会关闭后续历史保存，已有会话和历史保留。设置页没有统一的保存按钮；无效输入或存储失败会保留编辑值并显示错误。其他窗口修改的设置自动同步。

## 会话历史与删除

历史与模型偏好使用当前设备当前 Web origin 的 `localStorage`，数据为明文，不跨设备同步，不写入 Host profile patch，不保存 API 密钥或 Host 能力句柄。开启**允许保存会话历史到本地**后，历史保存主题/会话身份、固定序号、名称、备注、归档状态、当前原文草稿和默认值快照，以及已受理单元的原文、要求、语言、全部机器/人工修订、执行状态、安全实际调用 metadata 及最终选择，供重启恢复。每个修订正文只保存一份，事件与最终选择通过引用关联；不包含未保存的编辑草稿。

恢复记录不会继续或重新发送模型请求。重启前正在执行或未结算的修订显示 **重启前未确认／已中断**，原结果未知的情况会在说明中区分；核对后明确重译才会在同一个用户单元中发起新请求，恢复记录不能查询旧 Host 操作。新草稿在受理前失败时尚无已保存单元，其临时执行卡片不会恢复。所选文件也不进入历史，关闭面板、切换所属主窗口会话或删除所属翻译会话后释放；选择文件不代表已上传或可以执行文件翻译。DSH 模型消息历史尚未接入。

关闭历史保存后，已有历史继续保留，后续重命名、新单元、修订和最终选择只留在当前运行中，不替换已保存副本。模型偏好继续独立保存，只包含提供商 ID、模型 ID 与可选推理等级，恢复时为已有会话采用最新选择，不改写旧历史正文。删除会话会清除其专属偏好；历史清理保留所属主窗口的最后模型偏好，用作新会话默认选择。已保存主题仍保留不含正文的身份与编号记录，以避免重启后重用已发放序号；完全临时的新主题不因此落盘。重新开启会保存仍在内存中的当前内容，包括关闭期间的变化，不能恢复此前已经丢失的内容。设置页提供：

- **清除历史快译**：只处理已保存的快译会话。
- **清除所有会话历史**：处理本插件所有已保存会话，确认范围包含无法读取的历史副本。
- **删除所选历史**：勾选单条或多条会话后删除。

删除前需要确认，成功后从会话列表移除；右键删除同时处理该会话的内存内容与已保存历史。删除一个会话不会连带删除它的父子会话，历史清理范围包含已归档记录。主题术语默认保留，删除最后一个会话也不清除档案；需要一并清除时，在确认框明确勾选联动删除所选主题术语，未选中的同主题会话也会失去这些术语。确认同时冻结并检查会话与术语版本，陈旧范围拒绝执行；部分失败报告剩余范围，多项存储移除不宣称原子完成。

持久主题的新建、编号、重命名和相关存储操作使用浏览器 Web Locks 协调。环境不支持安全协调时，会提示能力不足并限制相关持久操作；纯临时内容仍可保留在当前窗口。锁只协调本版本参与相同协议的窗口，不把多项 `localStorage` 写入变成数据库事务。

读取或保存失败时保留当前输入；陈旧写入会提示冲突，读取本地副本需确认，覆盖必须显式选择。部分清理失败时会报告未完成状态；删除记录用于阻止旧副本再次自动导入。删除全部会话不重置仍保留主题的编号。

旧 v1 草稿和 schema2/3/4 会话可兼容读取。旧会话按可确认的父子关系归入主题并使用统一编号，旧显示名保留供查看；无法确认的关系保守分开。迁移不代表恢复了旧版从未记录的已删除编号。仅兼容读取不会改写已保存正文，明确开启保存或开启后的编辑才写入当前格式。包含文本记录的快照使用 schema5/history2，空记录仍使用 schema3；0.4.x 及更早版本不能读取 schema5。降级前请备份应用本地数据，避免用旧版修改同一份历史。导出的 JSON 是会话记录，当前不提供导入或恢复，不能代替上述备份。

旧版手动保存开关不会自动启用新版历史自动保存；新开关默认关闭。禁用或卸载插件不自动删除本机历史、术语或偏好，需要清理时请先明确操作。

## 兼容性与安装

此前核对的本机 Windows DSH Desktop 为 `0.2.0-rc.2`，用户当前 DSH 版本未重新确认。v0.7.1 于 2026-10-06 根代理验收：`npm test` 294 项、四个 Native 入口 38 项及仓库外独立检查 29 项（原常规 25 项、Native 3 项及新增定位检查 1 项）全部通过，均为 0 失败、0 取消、0 跳过。UI 检查使用轻量 hook renderer、合成事件和存储 fixture，浏览器下载接口为模拟；未验证实际 DOM、文件保存对话框或用户桌面。Native 检查加载真实 DSH `0.2.0-rc.2` 组件包，在一次性合成 profile 中使用 synthetic provider；四个入口分别检查 Quick Host、Client、挂载和主题工具，主题入口加载实际 Agent、AgentLoop、ToolRuntime、SessionController 与双向 Gateway，包含后台会话管理。挂载入口使用真实 `ClientRemoteService`、Cordis 与当前 Client bundle 检查自主能力查询、合成翻译、人工编辑/导出不增加模型调用及卸载。快译尚未经过用户桌面实测或真实远端模型验证。其他版本、操作系统和独立 Web profile 未验证。

新增定位检查使用真实安装的 Menu 定位逻辑、本次构建的发布 bundle 和合成尺寸，不是实际 DOM。用户于 2026-10-06 反馈进入具体模型或推理等级列表时闪烁，并明确 v0.7.0 新功能尚未测试；本次补丁后仍需桌面复测该菜单问题。

需要 Node.js 22 或更高版本、pnpm，以及支持本地 bundle 的 DSH。

```powershell
pnpm install --frozen-lockfile
pnpm build
```

在 DSH 插件管理器中将本目录作为 `dsh-translation-plugin` 本地 bundle 安装，启用后重启。构建产物位于 `dist/`，不进入 Git。以目录链接安装时，修改后重新构建同一目录。

从早期框架版升级时，需要在插件管理器刷新包含模型目录 RPC 的 bundle 元信息；没有刷新功能时卸载后重新安装，再重启 DSH。不要手动修改 profile。

若曾以 `dsh-deepseek-translation-plugin` 安装，请卸载旧名称后重新安装。启动异常时使用桌面端恢复选项禁用第三方插件，再查看诊断日志。

## 开发与许可证

请阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 和 [AGENTS.md](AGENTS.md)。提交采用 Conventional Commits，描述及正文使用中文；内部设计资料在本仓库之外管理。

`pnpm test` 会先构建，再验证会话、历史、旧格式兼容、目录及 Client 交互。Native 集成命令及 DSH 组件前提见 [CONTRIBUTING.md](CONTRIBUTING.md)。Synthetic provider 不代表真实远端模型，也不能代替用户桌面运行验证。

共享调用记录模块提供 RPC 可选 metadata，包含实际模型、推理等级、输出上限、提示词版本及已报告 token 使用量；Client 详情显示已记录的模型、推理等级、提示词版本和用量，已保存的浏览器记录与 JSON 导出另包含输出上限。未取得的配置版本与计数保持 `null`，不凭当前提示词推断旧调用；人工修订没有调用 metadata。

主题术语核心定义有范围的引用、版本、采用、冲突和精确检索。`TopicMemoryStore` 沿用现有 Web Locks 与历史开关，每个主题保存一份档案；`SessionStore` 仍是原文及最终选择的唯一权威。Host 工具只持有运行期执行范围，不另存术语或历史数据库。一次合并的远程贡献注册快译与主题管理两个命名空间，保持二者共存。

会话管理复用精简异步 Store 入口，在同一结构锁内核对预期元数据。原界面仍选中其新建或恢复的会话，模型工具采用后台参数。术语 JSON/Markdown 纯函数只投影冻结浏览器快照及引用标签，不重复证据正文。

变化见 [CHANGELOG.md](CHANGELOG.md)。当前本地版本为 `v0.7.1`，修正模型菜单定位。主模型后台会话管理、主题术语快照导出、纯文本快译重译、人工修订、最终选择、TXT/JSON 导出和可选重启恢复继续可用，模型偏好独立保存。普通模式执行和原主发送自动联动仍等待 DSH 官方扩展，文件翻译和完整知识系统也尚未接通；本地版本未远程发布。`private: true` 防止意外 npm 发布。
