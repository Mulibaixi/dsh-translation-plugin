# DeepSeek 翻译插件

[English](README.md) | [简体中文](README.zh-CN.md)

为 DeepSeek Harness（DSH）提供独立的翻译工作区，让翻译、讨论和长期资料积累各有位置。

主聊天用于讨论背景和提出要求，翻译工作区用于提交原稿、比较版本和交付译文，记忆资产用于积累同一主题的术语与背景资料。适合需要持续维护用词和语境的故事、游戏剧本及学术材料翻译。

## 为什么使用它

- **翻译与讨论分开**：原稿与译文留在翻译工作区，主聊天保留要求、解释和修改讨论。
- **同一主题持续积累**：多个翻译会话共享术语、实体、事实、关系和参考原件。
- **译文可以比较和修订**：保留不同版本，支持重译、人工编辑和最终版本选择。
- **记忆资产可见、可控**：查看来源依据，编辑、采用或停用条目，按需清理资料。
- **沿用 DSH 的模型配置**：为翻译选择已有模型与推理等级；嵌入检索可另配 API。

## 目前能做什么

| 能力 | 当前范围 |
| --- | --- |
| 快译 | 直接翻译纯文本，适合独立短句和临时查译。 |
| 普通翻译 | 主模型整理要求与背景，再调用翻译模型，支持讨论、重译和原文纠错。 |
| 文件翻译 | 读取文本或识读文件，按需分段翻译，审阅后通过会话中的版本入口交付。 |
| 主题与会话 | 新建主题及子会话、备注、排序、归档，在同一本地资料库内跨主聊天复用。 |
| 记忆资产 | 维护四类结构化档案、主题级／用户级设定及主题原文／双语对照文件。 |
| 记忆检索 | 普通搜索查找当前双语正文；嵌入 API 为有效档案、参考正文和当前译例提供语义检索。 |
| 版本与导出 | 保留旧版本、选择最终译文，按会话或主题导出译文 TXT 和对照 JSON。 |
| 保存与清理 | 宿主保存历史与记忆，按需加载；支持旧版、单元、会话、主题和插件五级清理。 |

项目仍处于开发阶段。文本／TXT 翻译可作为人工审阅的工作流使用，译文质量和记忆采用仍需核对，不承诺固定完成时间。构建、合成模型及浏览器检查不能代替真实模型质量和原生桌面操作验收。

## 环境与依赖

- DSH `0.2.0-rc.2` 或 `0.2.1-rc.2`，支持本地插件，并已配置可用模型。
- **快译**不要求 Composer 扩展；**普通模式**需要配套的 `dsh-composer-extension` 及与 DSH 版本匹配的 Composer 提交补丁。仅安装扩展不足以让官方原版支持材料联动发送。
- 配套源码使用内容协议 3 和任务阶段协议 2。翻译插件、Composer 扩展与宿主补丁需匹配；升级 DSH 后按扩展文档重新应用补丁。
- 文件候选资产提取使用 DSH 原生子代理，适配两版 DSH 的 run／Activation 接口；能力缺失会提示原因，主模型仍可直接读取文本原稿并翻译。
- 宿主需能加载内置 `node:sqlite`；从源码构建需要 Node.js 22 或更高版本、pnpm，以及并排放置的 Composer 扩展源码目录。

待译文件支持任意格式，每份最多 2 MiB。UTF-8 文本可直接读取；其他文件须先由主模型识读或 OCR。TXT、Markdown、JSON 和 HTML 译件可直接保存，其他输出格式取决于主模型能力。参考全文的可读格式见下文。

模型调用可能产生费用，本地保存不代表离线翻译。记忆资产窗口位于 DSH 应用内，可浮动或停靠。

## 安装与更新

### 安装

1. 先按 Composer 扩展的说明完成其构建，再在本插件目录执行：

   ```powershell
   pnpm install --frozen-lockfile
   pnpm build
   ```

2. 在 DSH 插件管理器中，将本目录作为 `dsh-translation-plugin` 本地插件安装并启用。普通模式还须启用配套 Composer 扩展和宿主补丁。
3. 重启 DSH，在主聊天右侧栏打开“翻译”。依赖不足时，按面板提示核对配套构建。

### 更新

先保存并备份需要保留的资料，再更新两个源码目录，依次构建 Composer 扩展和翻译插件，最后完整重启 DSH。仅构建或刷新页面不会替换运行中的宿主代码。

升级本版时注意：

- 旧浏览器测试历史不自动导入，重要内容应先导出；旧文件／文档任务需从当前文件输入重新发送原稿才能翻译。
- 参考文件统一为原文／双语对照文件。旧“其他参考资料”仅保留打开原件与删除；已有全文须完成主模型分段，才能建立新的语义索引。
- 新版保存的数据可能无法由旧版读取，不要让新旧版本同时使用同一份资料。导出文件目前不能导入恢复，不能替代完整数据备份。

禁用或卸载插件不会自动删除本地资料。版本变化见 [CHANGELOG](CHANGELOG.md)。

## 使用说明

### 1. 建立主题与翻译会话

首次打开选择**新建主题及首会话**或**选择已有主题**。主题归集同一故事或项目的记忆资产，翻译会话分开处理具体材料。同一本地资料库可在不同主聊天中继续使用；没有当前主聊天时也可浏览和管理已保存资料。

- 标题下拉中的 **+** 创建新主题；右键会话选择**新建子会话**，在原主题下继续工作。
- **重命名**修改主题名；**备注**只修改当前会话的显示名称。长按会话行后拖动可排序。
- **关闭**移出当前主聊天的打开列表；**归档**保留资料；**删除**清除内容并要求确认。

模型选择位于输入框右下角，目标语言和模式位于顶部。会话可以从快译升为普通；需要改回快译时另建会话。单元编号稳定，删除后不回填空号。

### 2. 快译：直接取得译文

选择快译模式、目标语言和模型，填写纯文本后发送。快译不读取主聊天上下文、主题记忆或参考资料，也不接收文件；需要术语一致性或背景资料时使用普通模式。

### 3. 普通翻译：结合要求与背景处理

**翻译输入框放原文，主聊天输入框放要求和讨论。** 先在当前主聊天中打开要使用的翻译会话，再选择发送方式：

- **连同要求发送**：在工作区准备文本或文件，在主聊天写明本次要求并发送。材料默认用于翻译；本次明确要求学习、讨论或暂不翻译时，按该要求处理。
- **直接发送材料**：点击工作区的发送按钮，请当前主模型翻译。主聊天输入框中尚未发送的文字不会一并提交。

材料发出后继续编辑输入框，不会改写已发送的原稿。原文纠错或修改译文时，在主聊天明确指出对应单元和要求，例如“参考单元 2、4 的用词，修改单元 5”；跨会话时附上会话名称。主模型可按需读取已打开会话的原文、定稿或指定版本。

普通文本和文件统一通过当前翻译流程处理。长原稿可按原文范围分段，结果须连续覆盖全文；主模型等待实际结果，先独立通读译文，再对照原文核验语义与表达，必要时在同一单元追加修订。自动审阅仍需人工核对。

文件原稿和各版译文显示为文件入口。默认通过会话交付，打开时生成可读文件名，同版重复打开复用同一份文件；只有明确要求独立导出时另存。文本结果保留原稿 BOM 和统一 CRLF 换行。JSON、HTML 等未指定输出形式时会先询问。

普通翻译读取适用设定与选定记忆。短文本可自动匹配参考原件中的相同表达；相似译例、长文件和背景事实由主模型检索、读取并选入上下文。修订携带准确旧译文，邻近对白使用有效最终版本；检索命中不等于一定正确采用。

撤回材料会通知主模型后续步骤；已执行的任务使用取消入口。重载后中断或结果未知时，先使用查询、取消或重译入口核对原任务，避免重复调用。重启不自动续跑模型请求，任务也不自动转交其他主聊天。

### 4. 记忆资产：维护主题的共同资料

从标题下拉的**记忆资产**或会话右键菜单进入，可切换查阅主题，不改变工作区当前会话。也可在主聊天提供资料并要求“学习资料”或“建立主题记忆”，由主模型读取实际材料、保留依据、检查已有内容并建档，无需先翻译文件。

| 类别 | 保存内容 |
| --- | --- |
| 术语 | 原词、译法及必要的含义或使用条件。 |
| 实体 | 人物、地点、组织等，以及别名和描述。 |
| 事实 | 主题中的重要事实，可关联实体。 |
| 关系 | 实体之间的联系，包括人物称谓及适用条件。 |
| 其他记忆 | 源文之外的主题级／用户级翻译设定，以及主题原文／双语对照文件。 |

四类档案中的条目可查看依据、新增、编辑、采用、停用或删除。主模型可修改已有条目；内容改变后回到待审阅，相同内容保留状态。冲突或依据变化时需复核。同主题会话共享资产，不同主题独立管理。

候选直接保存在相应类别中。**一键采用**处理当前主题、当前类别的全部待审及待复核条目，不受页内筛选影响；事实和关系的关联实体须先采用。暂不能采用的条目保留并显示未完成数量，候选不阻碍译文交付。

翻译采用优先级为：**用户指令 = 用户编辑确定的条目 > 用户审阅通过的条目 > 待审条目 = 模型理解**。用户指令与用户编辑条目冲突时请求指示；候选不会自动覆盖已生效资产，模型整理的说明也不会变成用户指令。

**翻译设定**可新建、编辑、启用、停用或删除，也可由主模型维护。普通翻译及重译完整读取全部适用的启用条目；用户级适用于当前本地资料库，其他要求默认当前主题。规则应精简、准确、保留适用条件，避免将单句修改、偶然译法或模型自检固化为通用要求。超过调用预算时会提示精简或停用。

**主题参考文件**只登记原文／双语对照文件，每份最多 2 MiB。列表显示文件名、分段进度和原件入口，不预览正文。上传后通知当前主模型标记分段边界，支持分批提交、中断后请求继续；程序按边界取原文，不重写原件，也不自动对齐或补造双语。

全文分段完整后，已配置的嵌入服务会排队建立索引；未完成时仍可打开、读取和字面查找。支持读取 UTF-8 TXT、Markdown、CSV、TSV、JSON、JSONL、LOG 和 RST；其他格式提供原件入口，学习内容可在主聊天提炼为资产或设定。

**译文记录**并排展示原文和译文，可选择会话或整个主题。普通搜索框只匹配当前原文与有效最终译文正文，英文不区分大小写，提供计数、高亮和上一处／下一处定位。页面固定文案、旧版和未定稿候选不参与；查找未完成会明确提示，不触发模型调用或自动定稿。图片、表格等可通过原件链接关联，链接本身不代表已解析或翻译。

### 5. 修订、定稿与导出

- **重译**追加版本，保留原稿和旧译文；短文本**编辑**追加人工版本。文件修改通过主聊天提出，外部编辑文件不会自动写回插件。
- 完整翻译自动建立最终选择，后续修订跟随更新；**设为最终**固定人工选择，新版本不会自动替换它。不完整或取消的输出不自动定稿。
- 同一文件的查找、导出和语义检索共用有效定稿；不同原稿的译文不会混用，旧版本默认不进入检索。
- 右键会话选择**导出译文 TXT**或**导出对照 JSON**，再选择当前会话或主题；记录页也提供导出。缺少定稿时会提示，可明确选择部分导出。主题档案另有 JSON／Markdown 导出。

导出不包含完整项目备份，也不提供导入恢复。发起下载后，请自行确认文件已保存。

### 6. 保存、存储与清理

在 **DSH 设置 → 翻译** 配置新会话默认模式、目标语言、要求和单次上限。有效设置即时保存；恢复默认不会清除历史或改写已有会话。

**嵌入 API**接受兼容 OpenAI Embeddings 的完整 HTTP(S) 地址（包含 `/embeddings` 路径）、模型名称和可选密钥。配置及密钥由宿主凭据服务保存，页面不回显密钥；更换服务主机需重新填写密钥。连接测试仅发送固定短文本，显示维度和耗时。

选择**保存并建立索引**或从记忆资产页进入**语义索引**，可建立、补齐或重建。索引包含有效实体、事实、关系、分段完整的参考全文，以及当前原文与有效定稿的译例；术语与启用设定直接读取。主模型检索限定当前主题的可访问内容，译例限于已打开会话，命中后可准确回读和选择上下文。未建立索引或接口失败时仍可词面查找，覆盖不足会明确说明。

建立索引会将相应正文发送给配置的嵌入服务。启用后随有效内容变化更新；修改服务地址或模型需重建。运行期向量保留在内存，已保存内容的向量由宿主保存，删除内容同步清理索引。

**允许保存会话历史到本地**控制历史和记忆资产的自动保存。开启后以宿主确认的状态为准；关闭后保留旧保存副本，后续内容仅留在运行期，重启可能丢失。模型偏好及嵌入配置独立保存。本地正文未加密，此开关不控制 DSH 主聊天、模型调用记录和附件。

启动先读取会话目录，打开、查阅或导出时按需加载正文；保存传输变化记录，失败时保留当前编辑并可重试或重新读取。删除最初创建资料的主聊天，不会删除已保存的翻译资料。

| 清理层级 | 作用 |
| --- | --- |
| 旧版本 | 删除可清理的旧原稿或译文正文及其独占资源，保留版本号与调用事实。最终／最新结果、保留修订的基础及未结算任务受保护。 |
| 单元 | 清除单元的各版正文、从属记录和资源引用，保留编号与调用统计。 |
| 会话 | 删除会话内容及从属资源，默认保留主题记忆。 |
| 主题 | 删除主题、会话、主题资产及参考登记，保留用户级设定和其他主题使用的共享文件。 |
| 插件 | **清除本地数据**移除本插件资料、设置、索引及专属嵌入凭据，保留用户原文件和 DSH 主聊天。 |

清理需确认，内容先失效，再释放独占文件；共享原件按实际使用保留。**存储与空间**可查看占用、删除无法读取的历史副本、清理孤立记录，以及**回收未引用原稿**。文件删除失败时正文不会恢复，残留可在重启后继续回收；文档还可清理未采用翻译块。

相关任务运行中或结果未知时先核对。已导出的文件、用户原件及已发送给主模型的内容不会随本地删除撤回。

## 运行诊断与问题反馈

普通文本机器版本提供**导出调用日志**，记录该版本的提示、输入、输出与执行事件。日志含翻译正文，按会话和版本校验，仅在原宿主运行期间可用；需要保留时先导出，分享前检查敏感内容。

在 DSH 宿主日志搜索 `[dsh-translation]`，按 `traceId` 关联操作；客户端保存或依据检查失败也会在浏览器控制台输出摘要。

| 阶段 | 说明 |
| --- | --- |
| `model.prepare`／`model.stream` | 模型准备、输出长度、完成／取消及失败阶段。 |
| `embedding.request` | 输入数量、HTTP 状态、返回维度和接口错误。 |
| `memory.index`／`memory.search` | 覆盖、词面／向量命中及降级情况。 |
| `history.write`／`history.cleanup` | 保存状态、删除、共享保留及残留清理。 |

摘要记录状态、耗时、错误码和堆栈位置，不包含正文、提示词、查询、接口地址或密钥。DSH 的模型会话记录另行管理，可能包含请求正文。接口连通、索引完成或日志显示成功，都不能单独证明译文与召回质量。

反馈时提供 DSH／插件版本、复现时间、操作、预期与实际现象，以及关联摘要。质量问题还需指出具体段落和判断依据。
