# DeepSeek 翻译插件

[English](README.md) | [简体中文](README.zh-CN.md)

用于 DeepSeek Harness（DSH）的翻译会话面板。处于早期开发阶段，已提供会话管理、模型选择和专用设置页，真实翻译执行尚未接入。

## 当前功能

- 右侧栏翻译面板，通过标题下拉栏切换已有会话；可折叠的会话侧栏默认收起，每个会话分别保留输入和配置。
- 新会话默认名称为“新翻译会话”，可重命名；从当前会话新建时按父会话名称编号，例如“故事A-01”“故事A-02”。当前只建立名称与父子关系，不复制原文或隐式继承记忆。
- 面板顶部当前标题左对齐，翻译模式和目标语言右对齐；标题支持下拉与右键操作，下方提供会话内容滚动区、圆形发送按钮和简洁输入框，输入时不显示蓝色聚焦边框。
- 模型选择位于输入框右下角、发送按钮左侧，采用 DSH 原生菜单与图标，并使用主窗口同一 `session.modelCatalog()` 目录接口。菜单包含模型与推理等级，可按提供商分组和搜索；选择只作用于当前翻译会话。
- **DSH 设置 → 翻译**：新会话默认值、历史保存开关及历史清理。有效修改即时保存。

翻译发送按钮暂不可用。目录查询只读取模型元数据，不发送翻译文本、不改变主聊天模型。正式译文消息、执行尝试、修订、记忆档案及正式导出尚未实现。上一版人工译文编辑与导出控件已从面板移除，保存过的旧人工稿仍可查看。

## 会话与默认设置

进入一个主窗口会话并展开右侧栏，从引导入口打开“翻译”。当前翻译会话按所属主窗口会话分别管理；每个翻译会话有自己的独立 ID。此归档范围不代表快译执行会使用主模型。

- 点击当前标题展开已有会话，选择后切换并保留各会话输入；下拉底部的居中 **+** 创建默认命名的新会话，下拉中也提供恢复归档入口。
- 会话侧栏按创建顺序显示使用中的会话；末尾的居中 **+** 创建默认命名的新会话。两个 **+** 入口均可整行点击，侧栏中的范围与会话名称行一致；悬停和无障碍名称仍为“新建翻译会话”。
- 右键会话名称或顶部当前标题，菜单提供 **新建会话、重命名、删除、归档**。已展开的标题下拉栏在右键操作时保持显示；Escape 先退出右键菜单，点击外部收起两层菜单。“新建会话”从被点击的会话按名称编号新建，无需先切换到该会话。
- 归档保留内容、从使用列表移除。展开 **已归档** 后点击会话可恢复使用，也可右键选择 **恢复归档**；没有关闭会话功能。
- 会话侧栏默认收起，顶部侧栏图标可展开或收起列表。会话名称过长时省略显示，悬停可查看完整名称。
- 历史保存关闭时，未落盘内容及归档/恢复等变化只在当前窗口保留，刷新、重启或插件重载后丢失。开启后自动保存当前窗口内会话，包括归档状态。

模型菜单先选择 **模型**，再通过 **推理等级** 选择适配器提供的等级，菜单字号与目标语言菜单一致。适配器允许未指定等级时提供 **Default**；未提供推理元数据的模型会明确提示，没有可选等级。

新会话从设置复制翻译模式、目标语言、翻译要求与单次上限。已有会话不会因默认值变化而被改写。模式切换保留当前会话输入。

| 设置 | 默认值与行为 |
| --- | --- |
| 翻译模式 | 快译。 |
| 目标语言 | 中文。 |
| 翻译要求 | 留空；最多 4000 个 Unicode 字符。 |
| 单次上限 | 原文 20000 个 Unicode 字符，可设为 1–200000；不是 token 上限。 |
| 允许保存会话历史到本地 | 关闭；开启后自动保存当前窗口内会话及后续编辑，包括归档状态。 |

**恢复默认设置**位于设置页顶部。恢复默认会关闭后续历史保存，已有会话和历史保留。设置页没有统一的保存按钮；无效输入或存储失败会保留编辑值并显示错误。其他窗口修改的设置自动同步。

## 会话历史与删除

历史使用当前设备当前 Web origin 的 `localStorage`，数据为明文，不跨设备同步，不写入 Host profile patch，不保存 API 密钥。目前历史保存会话名称、关系、归档状态、输入、默认值快照和模型选择；模型消息历史尚未接入。

关闭历史保存只停止后续写入，已有历史继续保留。设置页提供：

- **清除历史快译**：只处理已保存的快译会话。
- **清除所有会话历史**：处理本插件所有已保存会话，确认范围包含无法读取的历史副本。
- **删除所选历史**：勾选单条或多条会话后删除。

删除前需要确认，成功后从会话列表移除；右键删除同时处理该会话的内存内容与已保存历史。删除一个会话不会连带删除它的父子会话。历史清理范围包含已归档记录。确认期间内容发生变化会拒绝陈旧删除。确认框询问是否联动删除关联记忆档案；当前记忆系统尚未接入，联动删除暂不可选。共享记忆范围需在后续记忆设计中确定。

读取或保存失败时保留当前输入；跨窗口陈旧写入会提示冲突，读取本地副本需确认，覆盖必须显式选择。`localStorage` 没有原子读写事务，冲突检查不能保证完整跨窗口锁。部分清理失败时会提示重新选择后重试。

旧版已保存草稿可作为历史读取，旧默认值也可迁移。旧版手动保存开关不会自动启用新版历史自动保存；新开关默认关闭。禁用或卸载插件不自动删除本机历史或偏好，需要清理时请先在设置中明确操作。

## 兼容性与安装

已核对的本机 Windows DSH Desktop 为 `0.2.0-rc.2`。用户此前确认框架安装、卸载和加载，并提供上一版会话栏与主窗口输入框截图；本轮侧栏、右键操作、归档与推理等级菜单仍待桌面实测。其他版本、操作系统和独立 Web profile 未验证。

需要 Node.js 22 或更高版本、pnpm，以及支持本地 bundle 的 DSH。

```powershell
pnpm install --frozen-lockfile
pnpm build
```

在 DSH 插件管理器中将本目录作为 `dsh-translation-plugin` 本地 bundle 安装，启用后重启。构建产物位于 `dist/`，不进入 Git。以目录链接安装时，修改后重新构建同一目录。

本轮新增模型目录 RPC 的 Client 依赖。已有安装需要在插件管理器刷新 bundle 元信息；没有刷新功能时卸载后重新安装，再重启 DSH。不要手动修改 profile。

若曾以 `dsh-deepseek-translation-plugin` 安装，请卸载旧名称后重新安装。启动异常时使用桌面端恢复选项禁用第三方插件，再查看诊断日志。
